# LangChain OpenAI App with LangSmith Tracing

A beginner-friendly Python application that uses LangChain to interact with an OpenAI chat model and LangSmith to trace and monitor application runs.

## Features

- Uses LangChain to communicate with an OpenAI model
- Sends a prompt and prints the model response
- Enables LangSmith tracing
- Displays application runs in the LangSmith dashboard
- Uses environment variables for API keys
- Keeps API keys secure and out of the source code

## Technologies

- Python
- LangChain
- OpenAI
- LangSmith
